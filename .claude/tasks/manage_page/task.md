У нас готов дизайн сайта и все грузится хардкордно. Нужно сделать возможность редактирования контента. Если пользователь залогинился и у него есть пермишен на редактирование страниц, то, когда он заходит на сайт и гуляет по страницам, у него появляется возможность редактировать любой элемент. Теперь конкретней про редактирование, как я вижу этот процесс и архитектуру:
каждая старница (к примеру главная) хранится в виде json в таблице pages_json_content. При загрузке страницы мы дёргаем backend и получаем json страницы. Вот пример для главной страницы:
```json
    {
        "header": {
            "enabled": true,
            "elements": {
                "phone_number_one": {
                    "content": "+7 (423) 230-20-20",
                    "type": "string",
                    "enabled": true
                },
                "city_one": {
                    "content": "Владивосток",
                    "type": "string",
                    "enabled": true
                },
                .....
                "main_header" : {
                    "content": "Кратчайший путь вашего груза",
                    "type": "html",
                    "enabled": true
                },
                "blocks": [
                    {
                        "content": {
                            "icon": {
                                "content": "path to image, or image name from nuxt ui",
                                "type": "image",
                                "enabled": true
                            },
                            "middle_text": {
                                "content": "2014",
                                "type": "text",
                                "enabled": true
                            },
                            "bottom_text": {
                                "content": "Год основания",
                                "type": "text",
                                "enabled": true
                            }
                        },
                        "type": "aggregate",
                        "enabled": true
                    }
                ] 
            }
        }
    }
```

При редактировании в зависимости от type открывать редактор либо html либо просто форма для ввода текста либо выбор картинок. Так же может быть загрузка файлов (к примеру страница с тарифами где можно добавить файлы). На это примере я могу динамически добавлять блоки. К примеру если это aggegate, дать возможность добавлять или удалят элементы в массив content. Так же через enabled есть возможность выключать элемент. Такую структуру нужно придумать для всех страниц. Я думаю сам элемент должен выглядет вот так:
<span cms-editable="true" cms-path="header.phone_number_one">{{ content from cms-path }}<span/>
После редактирования должна сбоку страницы показываться всплывашка: применено. 
Я описал примерную идею как я это вижу. Суть в том чтобы администратор мог редактировать контент в живую. Давай обсудим этот подход, предложи свой если считаешь как лучше
